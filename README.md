## Purpose
This app allows the uploading of .csv data files to prepared excel templates, which store graphs (IV, CV, breakdown voltages) and parameters (barrier heights, ideality factors, breakdown voltages, .etc) that can be extracted from the .csv data. 
## Stacks
Database: Microsoft SQL Server
Backend: C# .NET with NUnit and Moq for unit testing
Frontend: JavaScripy React
